# AskED

## AI-Powered Learning and Instant Doubt-Solving Platform

AskED is a full-stack educational platform built to make learning faster, simpler, and more accessible.

The platform combines an AI Study Buddy, instant doubt solving, camera-based question solving, academic Q&A, student-teacher collaboration, and real-time application data into one unified learning experience.

> **Ask anything. Understand everything.**

## 🎯 Why AskED?

Students often spend a lot of time searching across different websites, videos, notes, and forums just to understand one question.

AskED aims to simplify that experience.

A student can:

1. Open AskED
2. Capture or upload a question
3. Let AI understand the question
4. Receive a step-by-step explanation
5. Ask follow-up questions
6. Continue learning

The goal is simple:

> **Turn every doubt into an opportunity to learn.**

# ✨ Features

## 🤖 AI Study Buddy

AskED includes an AI-powered study assistant designed to behave like a personal academic tutor.

Students can:

- Ask academic questions
- Get step-by-step explanations
- Request simpler explanations
- Ask for examples
- Ask for additional steps
- Generate practice questions
- Continue with follow-up questions
- Learn concepts instead of simply receiving answers

The AI is designed to support subjects including:

- Mathematics
- Physics
- Chemistry
- Biology
- Computer Science
- Programming
- Data Structures and Algorithms
- Database Management Systems
- Operating Systems
- Artificial Intelligence
- Machine Learning
- Deep Learning
- Natural Language Processing
- Statistics
- And other academic subjects

# 📷 Camera-Based Doubt Solver

One of the core experiences of AskED is instant visual doubt solving.

Instead of manually typing a long question, students can capture it using their device camera.
